
# HTTP-server

Многопоточный HTTP/1.1-сервер на C++20.

Курс: Многопоточное программирование на C++.

## Вариант

Вариант 5 — Lock-free пул потоков.

Требуется реализовать пул рабочих потоков с собственной
lock-free MPMC (или MPSC) очередью на std::atomic.

## Состояние проекта

Неделя 1 — начальный каркас проекта.

Реализовано:
- Сборка через CMake.
- Структура проекта.
- Обработка параметров --port и --threads.
- Тестовый запуск Hello World.

HTTP-соединения пока не обрабатываются.

## Сборка

Требуется C++20, CMake, GCC >= 12 или Clang >= 15.
Целевая платформа — Linux x86_64.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
```

## Запуск

```bash
./build/server --port 8080 --threads 8
```

## Архитектура (план)

Проект разделён на независимые модули:

- Config — конфигурация и аргументы командной строки.
- Server — управление жизненным циклом сервера.
- Network — работа с POSIX sockets.
- HTTP — парсинг запросов и формирование ответов.
- Router — маршрутизация HTTP-запросов.
- ItemStore — хранение объектов и синхронизация доступа.
- MPMCQueue — собственная lock-free очередь.
- WorkerPool — рабочие потоки, выполняющие задачи.

На первой неделе реализованы только Config и каркас Server.

Планируется ограниченная кольцевая MPMC-очередь
с атомарными счётчиками и номерами последовательности
ячеек. Это позволит избежать ручного освобождения
динамических узлов очереди.

Точный выбор memory_order и обоснование будут
добавлены при реализации очереди на четвёртой неделе.
